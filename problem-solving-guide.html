Problem Solving vs DSA

حل المسائل البرمجية (Problem Solving) هو مهارة تحويل مسألة غير واضحة إلى خوارزمية قابلة للتنفيذ — بينما DSA هي الأدوات (هياكل البيانات والخوارزميات) التي تستخدمها.

🔧DSA = أدوات في صندوق العمل. Problem Solving = معرفة أي أداة تستخدم ومتى — ومش بس الحفظ، بل التفكير تحت ضغط الوقت.
المفهومالتركيزمثال
Problem SolvingPattern recognition، decomposition، optimization"إزاي ألاقي أطول substring بدون تكرار؟"
DSAImplementation، complexity، correctnessSliding window على string + hash set
Coding InterviewCommunication + clean code + edge casesTwo Sum في 30 دقيقة مع شرح صوتي
Easy / Medium / Hard

Easy = pattern واحد واضح. Medium = pattern + twist. Hard = دمج patterns أو optimization غير بديهي.

Live Coding vs Take-home

Live: speed + communication. Take-home: code quality + tests + design doc.

اختيار اللغة

Python (سرعة كتابة)، Java/C++ (typed، interviews)، JavaScript (frontend roles). المهم: إتقان لغة واحدة.

قراءة المسألة

اقرأ مرتين. حدد input/output، constraints (n ≤ 10⁵؟)، duplicates؟ negative numbers؟ sorted؟

Fundamentals & Recursion

Loops، conditionals، وinvariants (شرط يظل صحيحاً أثناء الحل) — أساس كل pattern. Recursion = function تستدعي نفسها مع base case.

Loop Invariant

مثال sliding window: "كل عناصر النافذة تحقق الشرط X". تحقق قبل/أثناء/بعد الحلقة.

Recursion Stack

كل استدعاء = frame على call stack. Stack overflow ≈ depth > 10⁴ (Python default ~1000).

Iterative vs Recursive

Recursive: أنظف للـ trees/backtracking. Iterative: أسرع، بدون stack overflow.

Memoization Intro

cache نتائج subproblems → bridge لـ DP. fib(n) من O(2ⁿ) إلى O(n).

Python
def fib(n, memo={}):
    if n <= 1: return n
    if n in memo: return memo[n]
    memo[n] = fib(n-1, memo) + fib(n-2, memo)
    return memo[n]
⚠️
نسيان base case = infinite recursion. في DP: define state clearly قبل الكود.

Arrays, Strings, LinkedList, Stack, Queue

الهياكل الخطية هي الأساس — معظم المسائل تبدأ من array أو string أو linked list.

Arrays vs Lists
Array (Dynamic Array)

Contiguous memory — random access O(1). Append amortized O(1). Insert/delete middle O(n). Python list، Java ArrayList، C++ vector.

Linked List

Nodes chained by pointers — insert/delete O(1) at known node، no random access O(n). Java LinkedList، Python: implement or use deque for similar ops.

Arrays & Strings
1D Arrays

Random access O(1). Insert/delete middle O(n). Two pointers for pairs، prefix sum for ranges. In-place swap from both ends.

2D Matrix

Row-major storage. Rotate 90°: transpose + reverse rows. Spiral traversal: boundary shrinking. Islands = grid DFS.

Strings

Immutable في Python/Java — build with list + join (StringBuilder pattern). Anagram، palindrome، substring search.

Interview Tips

Linked Lists
Singly Linked List

Node: val + next. Head pointer. Insert/delete O(1) at head. Search O(n).

Doubly Linked List

Node: val + prev + next. Delete node in O(1) with pointer. LRU Cache uses this. Reverse both directions.

Circular Linked List

Last node points to head. Useful for round-robin scheduling. Floyd cycle detection works on any variant.

Classic Operations

Floyd cycle detection، reverse list، merge two sorted، reverse k-group، reorder list.

Stack & Queue
Stack (LIFO)

Valid parentheses، evaluate RPN، monotonic stack (next greater element)، DFS iterative، undo/redo.

Queue / Deque (FIFO)

BFS shortest path، sliding window maximum (monotonic deque)، circular queue for bounded buffer.

Python
# Valid parentheses — stack O(n)
def is_valid(s):
    stack, pairs = [], {")": "(", "]": "[", "}": "{"}
    for c in s:
        if c in pairs:
            if not stack or stack.pop() != pairs[c]: return False
        else: stack.append(c)
    return not stack
Python
# Reverse linked list — O(n) time, O(1) space
def reverse(head):
    prev, curr = None, head
    while curr:
        nxt = curr.next
        curr.next = prev
        prev, curr = curr, nxt
    return prev

Hashing & Trees
Hash Map, BST, Heap, Trie

Hash maps للـ O(1) lookup. Trees للـ hierarchical data. Heaps للـ top-K. Trie للـ prefixes.

Hashing
Hash Map / Hash Set

Map (dict): key→value — two sum، frequency. Set: unique elements — cycle detection in graph، dedup. Collision: chaining أو open addressing.

Complexity

Average O(1) insert/lookup/delete. Worst O(n) if all keys collide. Space O(n).

Python
# Group anagrams — hash by sorted key or char count
from collections import defaultdict
def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = tuple(sorted(s))
        groups[key].append(s)
    return list(groups.values())
Binary Trees
Complete Binary Tree

Every level filled except possibly last — filled left to right. Heaps are complete trees. Height = O(log n). Array storage: parent i → children 2i+1, 2i+2.

Balanced Binary Tree

Height difference left/right ≤ 1 (AVL) or roughly balanced (Red-Black). Guarantees O(log n) search/insert. Unbalanced skewed tree → O(n) worst case.

Inorder

Left → Root → Right. BST inorder = sorted order.

Preorder

Root → Left → Right. Serialize tree structure.

Postorder

Left → Right → Root. Delete tree، evaluate expression.

Level Order

BFS with queue. Zigzag = reverse every other level.

Height / Diameter

Height: 1+max(left,right). Diameter: max path through any node.

BST Operations

Search/insert O(h). Validate: min/max range per node. kth smallest: inorder.

Python
# Validate BST — range (min, max) per node
def is_valid_bst(root, lo=float('-inf'), hi=float('inf')):
    if not root: return True
    if not (lo < root.val < hi): return False
    return is_valid_bst(root.left, lo, root.val) and is_valid_bst(root.right, root.val, hi)
Heap & Trie
Min-Heap

Parent ≤ children. Root = minimum. Python heapq is min-heap. top-K largest: maintain size-k min-heap.

Max-Heap

Parent ≥ children. Root = maximum. In Python: negate values or use -x trick with heapq. top-K smallest: size-k max-heap.

Trie

Prefix tree — each node = char. Autocomplete, word search II, longest common prefix. Space O(total chars).

Heap vs BST

Heap: O(1) min/max, O(log n) insert. BST: O(log n) search ordered. Use heap for priority queue / top-K.

Python
# Max-heap trick in Python — negate values
import heapq
def k_smallest(nums, k):
    h = [-x for x in nums[:k]]
    heapq.heapify(h)
    for x in nums[k:]:
        if x < -h[0]: heapq.heapreplace(h, -x)
    return [-x for x in h]
Python
# Level-order BFS
from collections import deque
def level_order(root):
    if not root: return []
    q, res = deque([root]), []
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
        res.append(level)
    return res

# Trie node — insert & search prefix
class TrieNode:
    def __init__(self):
        self.children = {}
        self.end = False
class Trie:
    def __init__(self): self.root = TrieNode()
    def insert(self, word):
        node = self.root
        for c in word:
            node = node.children.setdefault(c, TrieNode())
        node.end = True

Graphs & Advanced DS
Representations, Union-Find, Segment Tree

Graphs = nodes + edges. Advanced structures للـ range queries وconnected components.

Representations

Adjacency list: O(V+E) space, best for sparse. Matrix: O(V²), O(1) edge lookup.

Directed vs Undirected

Directed: one-way edges (Twitter follow، prerequisites). Undirected: two-way (friendship، roads). Weighted vs unweighted affects algorithm choice.

Union-Find (DSU)

Path compression + union by rank → nearly O(1) amortized. Connected components, Kruskal MST.

Segment Tree / BIT

Range sum/min queries + point updates in O(log n). Fenwick Tree (BIT) simpler for prefix sums.

Python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return
        if self.rank[ra] < self.rank[rb]: ra, rb = rb, ra
        self.parent[rb] = ra
        if self.rank[ra] == self.rank[rb]: self.rank[ra] += 1

def is_palindrome(s):
    l, r = 0, len(s)-1

        if s[l] != s[r]: return False
        l += 1; r -= 1

def two_sum_sorted(nums, target):
    l, r = 0, len(nums)-1
    while l < r:
        s = nums[l] + nums[r]
        if s == target: return [l+1, r+1]

def longest_unique(s):
    seen, l, best = {}, 0, 0
    for r, c in enumerate(s):
        if c in seen and seen[c] >= l: l = seen[c]+1
        seen[c] = r
        best = max(best, r-l+1)
    return best

def subarray_sum(nums, k):
    count, pre, mp = 0, 0, {0: 1}
    for x in nums:
        pre += x
        count += mp.get(pre - k, 0)
        mp[pre] = mp.get(pre, 0) + 1
    return count

Sorting & Binary Search Order

def merge_intervals(iv):
    iv.sort(key=lambda x: x[0])
    out = [iv[0]]
    for s, e in iv[1:]:
        if s <= out[-1][1]: out[-1][1] = max(out[-1][1], e)
        else: out.append([s, e])
    return out

def binary_search(nums, target):
    lo, hi = 0, len(nums)-1
    while lo <= hi:
        mid = lo + (hi-lo)//2
        if nums[mid] == target: return mid
        if nums[mid] < target: lo = mid+1
        else: hi = mid-1
    return -1

def bfs(start, adj):

from collections import deque
def max_sliding_window(nums, k):
    dq, out = deque(), []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x: dq.pop()
        dq.append(i)
        if dq[0] <= i-k: dq.popleft()
        if i >= k-1: out.append(nums[dq[0]])
    return out

# Subsets — each level: include or skip → 2^n leaves
def subsets(nums):
    res, path = [], []
    def dfs(i):
        if i == len(nums):
            res.append(path[:]); return
        path.append(nums[i]); dfs(i+1); path.pop()  # include
        dfs(i+1)                                      # skip
    dfs(0); return res

Backtracking Choose/undo
DFS + undo when path fails; prune early.
Examples: Subsets, Permutations, Combination Sum, N-Queens
⏱ O(2ⁿ) or O(n!)⚠️ Template: choose → explore → unchoose
Python
def permute(nums):
    res = []
    def dfs(path, used):
        if len(path) == len(nums):
            res.append(path[:]); return
        for i, x in enumerate(nums):
            if used[i]: continue
            used[i] = True; path.append(x); dfs(path, used)
            path.pop(); used[i] = False
    dfs([], [False]*len(nums)); return res

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        if self.rank[ra] < self.rank[rb]: ra, rb = rb, ra
        self.parent[rb] = ra
        if self.rank[ra] == self.rank[rb]: self.rank[ra] += 1
        return True

def solve_n_queens(n):
    res, cols, diag1, diag2 = [], set(), set(), set()

        if r == n: res.append(board[:]); return

        buckets[int(x * k)].append(x)
    out = []
    for b in buckets:
        out.extend(sorted(b))
    return out
✅
Python sorted() = Timsort O(n log n) stable. Use .sort() in-place when order among equal elements matters.

أخطاء شائعة
Common Mistakes & Tricky Parts

تجنب هذه الأخطاء — بتظهر في 90% من الـ failed interviews. قائمة CTCI-style للـ tricky parts.

Logic & Loop Bugs
Off-by-One Errors

Window boundaries، i < n vs i <= n، inclusive vs exclusive ranges. Binary search: lo <= hi vs lo < hi.

Infinite Loops

Binary search: forget to update lo/hi. While loop: condition never changes. Graph BFS: re-queue visited nodes.

Out of Range

Array index -1 or len(arr). Grid: row/col bounds. Empty input before accessing arr[0]. Always check bounds first.

Too Many Nested Loops

O(n³) or worse hidden in 3 nested loops. Look for hash map / sort to reduce. Repeated scans → prefix sum.

Data & Numeric Pitfalls
Integer Overflow

Python OK for big ints. Java/C++: use long. Sum/product of large values — mod early with MOD = 10⁹+7.

int vs double / Float Precision

Never compare floats with ==. Use epsilon: abs(a-b) < 1e-9. Division may need float: a/b vs a//b. Financial: use integers (cents).

Divide by Zero

Check denominator before /. Modular inverse requires gcd(a,MOD)=1. Average: count > 0 before sum/count.

Null Pointer / None

Java NPE، Python None. Tree: if not root. Linked list: check node before node.next. Always handle empty input.

Code Quality & Edge Cases
StringBuilder Pattern

❌ Java: s += c in loop → O(n²). ✅ StringBuilder.append(). Python: list + join. C++: ostringstream.

Date & Time

Convert to epoch/unix timestamp for comparison. Watch timezones، daylight saving. Java: LocalDateTime، Python: datetime. Leap years for calendar problems.

Edge Case Checklist

Empty، single element، duplicates، all same value، sorted/reverse sorted، max/min n، negative numbers، null root.

Too Many if/else

Refactor to hash map lookup، polymorphism، or early return. State machine table for complex branching.

Repeated Code (DRY)

Extract helper functions. Same loop body twice → merge. Copy-paste bugs are common in interviews.

Modify While Iterating

Don't remove from list during for-loop. Use new list، iterate backwards، or mark-and-sweep.

Wrong Base Case (Recursion/DP)

dp[0], empty string, leaf node. Off-by-one in memo indices.

Duplicates in Backtracking

Sort + skip identical at same level. Hash set for "used" tracking in permutations.

12 High-Frequency Walkthroughs

كل walkthrough يتبع الـ 7-step framework — تدرّب عليهم حتى تشرحهم بدون تفكير.

Two Sum

Clarify & Restate

Given unsorted array and target, return indices of two numbers that sum to target. Exactly one solution exists.

Examples / Edge Cases

[2,7,11,15], target=9 → [0,1]. Edge: min length 2. No duplicate use of same index.

Brute Force

Nested loops: for i, for j>i, if nums[i]+nums[j]==target return [i,j]. Time O(n²), space O(1).

Optimize

Hash map stores value→index. For each x at i, if target-x in map, return. One pass O(n) time, O(n) space.

Code

Use dict seen. Don't overwrite index before checking — or check before insert.

Test

Walk [2,7,11,15], t=9: i=0, 2 not in map, seen={2:0}. i=1, 7, need 2 → found at 0. Return [0,1].

Complexity

O(n) time, O(n) space. Cannot do O(1) space without sort (then two pointers O(n log n)).

Valid Parentheses

Clarify

String of ()[]{} only. Open must close same type in correct order. Empty valid.

Examples

'()[]{}' ✓, '(]' ✗, '([)]' ✗, '{[]}' ✓.

Brute Force

Replace '()' '' repeatedly until empty or stuck — O(n²). Not ideal.

Optimize

Stack: push opens. On close, pop must match. End stack empty.

Code

Map closing→opening. For c in s: if c in map, need stack and stack[-1]==map[c] else push.

Test

'([{}])' — push (, [, {. Pop } match {. Pop ] mismatch? Actually } closes { OK, ] closes [ OK, ) closes ( OK.

Complexity

O(n) time, O(n) space for stack.

Merge Two Sorted Lists

Clarify

Two sorted linked lists → merge one sorted list. Return head.

Examples

1→3→5 + 2→4→6 → 1→2→3→4→5→6. Empty l1 → l2.

Brute Force

Collect values, sort, rebuild — O(n log n). Wastes sorted property.

Optimize

Dummy node, compare l1.val vs l2.val, attach smaller, advance pointer.

Code

tail = dummy. While both: if l1.val<=l2.val attach l1 else l2. Attach remainder.

Test

1,3,5 vs 2,4 — pick 1, pick 2, pick 3, pick 4, attach 5.

Complexity

O(n+m) time, O(1) extra space.

Binary Tree Level Order

Clarify

Return values level by level as list of lists. Left to right per level.

Examples

[3,9,20,null,null,15,7] → [[3],[9,20],[15,7]]. Empty → [].

Brute Force

BFS without level separation — then group by depth with hash map.

Optimize

Queue BFS: each iteration process len(q) nodes = one level.

Code

deque([root]). While q: level=[], for _ in range(len(q)): pop, add val, push children.

Test

Root 3: level0=[3]. Push 9,20. level1=[9,20]. Push 15,7. level2=[15,7].

Complexity

O(n) time, O(n) queue space worst case (last level).

Number of Islands

Clarify

Grid '1' land '0' water. Connected 4-directionally. Count islands.

Examples

Single '1' → 1. All '0' → 0. Diagonal not connected.

Brute Force

Visited matrix + BFS each unvisited '1' — same as optimal.

Optimize

DFS sink island: mark '1'→'0' when visited. Count DFS calls.

Code

For each cell if '1': count++, dfs flood fill.

Test

2x2: 11/01 → two islands? 11 top row one island, 01 bottom — 1 at (1,0) separate = 2.

Complexity

O(rows×cols) time and space for recursion stack.

Course Schedule

Clarify

n courses, prerequisites [a,b]= must take b before a. Can finish all?

Examples

n=2, [[1,0]] → true. n=2, [[1,0],[0,1]] → cycle false.

Brute Force

Try all orderings — O(n!) impossible.

Optimize

Topo sort: if cycle in prereq graph, impossible. Kahn BFS indegree.

Code

Build adj reversed (b→a), indegree[a]++. Queue indegree 0. Process all? seen==n.

Test

Cycle 0↔1: both indegree 1, queue empty, seen=0≠2.

Complexity

O(V+E).

Coin Change

Clarify

Coins unlimited, min coins for amount. Return -1 if impossible.

Examples

coins=[1,2,5], amount=11 → 3 (5+5+1). amount=3, coins=[2] → -1.

Brute Force

Recursion try each coin — exponential without memo.

Optimize

DP: dp[a]=min coins for amount a. dp[a]=min(dp[a-c]+1) for c in coins.

Code

dp[0]=0, rest inf. Loop a 1..amount, inner loop coins.

Test

amount=11: dp builds up 1,2,1,2,1,2,2,3,3,2,3 for 10, then 3 for 11.

Complexity

O(amount × |coins|) time, O(amount) space.

Longest Increasing Subsequence

Clarify

Strictly increasing subsequence (not contiguous). Return length.

Examples

[10,9,2,5,3,7,101,18] → 4 (2,3,7,101).

Brute Force

Generate all 2^n subsequences — too slow for n=10⁵.

Optimize

Patience sorting: tails[i]=smallest tail of LIS len i+1. Binary search insert x.

Code

bisect_left on tails. If x > all tails, append else replace.

Test

Process 10: tails=[10]. 9: replace → [9]. 2: [2]. 5: [2,5]. ...

Complexity

O(n log n) time, O(n) space.

Word Break

Clarify

String s, wordDict. Can s segment into dictionary words? Reuse words OK.

Examples

'leetcode', ['leet','code'] → true. 'catsandog', ['cat','cats'...] → false.

Brute Force

Recursion try all split points — O(2^n).

Optimize

dp[i]=can segment s[0:i]? dp[0]=True. For j

Code

wordSet=set(dict). Optimize j from max(0,i-maxLen) to i.

Test

'leetcode': dp at 4 true (leet), dp at 8 true (code).

Complexity

O(n² × m) with word length m for hash lookup.

Merge Intervals

Clarify

Array of [start,end]. Merge all overlapping.

Examples

[[1,3],[2,6],[8,10]] → [[1,6],[8,10]]. Touching [1,4][4,5] → merge? Usually yes if <=.

Brute Force

Repeatedly merge any overlap until stable — O(n²).

Optimize

Sort by start. If current start <= last end, extend last end. Else append.

Code

out=[intervals[0]]. For s,e in intervals[1:]: merge or append.

Test

[1,3][2,6]: 2<=3 extend to [1,6]. [8,10] new.

Complexity

O(n log n) from sort.

LRU Cache

Clarify

Capacity cap. get(key) return val or -1. put(key,val) evict LRU if full. O(1) both.

Examples

cap=2: put(1,1), put(2,2), get(1)→1, put(3,3) evicts key 2.

Brute Force

Dict + timestamp list — O(n) eviction.

Optimize

HashMap key→Node in doubly linked list. Head=MRU, tail=LRU.

Code

get: move node to head. put: update or insert head, evict tail if over cap.

Test

After get(1), 1 is MRU. put(3) evicts 2 not 1.

Complexity

O(1) get and put.

Clarify

Elevation map array. How much water trapped after rain?

Examples

[0,1,0,2,1,0,1,3,2,1,2,1] → 6.

Brute Force

For each i, water += min(maxLeft,maxRight)-height[i] if positive. O(n²).

Optimize

Two pointers l,r with maxL,maxR. Move smaller side — water on that side determined.

Code

Test

Classic array — pointer approach accumulates 6.

Complexity

O(n) time, O(1) space.

Serialize / Deserialize Binary Tree

Clarify

Design codec: serialize tree to string, deserialize back. Same structure.

Examples

[1,2,3,null,null,4,5] round-trip. Empty tree → 'null' or empty.

Brute Force

JSON with nested objects — works but verbose.

Optimize

BFS preorder with null markers, or comma-separated BFS level order.

Code

Serialize: queue, append val or 'null'. Deserialize: split, rebuild with queue of indices.

Test

Root 1, children 2,3 — string '1,2,3,null,null,null,null' style BFS.

O(n) both operations.
