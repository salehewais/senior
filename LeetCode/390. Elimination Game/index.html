When head moves

The survivors are always head, head + step, head + 2·step, … (remaining terms). Each pass deletes every other term and flips direction. Head moves when left_to_right or remaining % 2 == 1. A left-to-right pass always deletes the first survivor. A right-to-left pass deletes it only when the count is odd: the rightmost index is even, so stepping by two lands on index 0. Then remaining is halved, step doubles, and the direction flips.
