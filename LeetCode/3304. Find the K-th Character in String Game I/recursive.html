Find the K-th Character

If k is 1, the character is a. Otherwise jump to k minus the largest power of two below k, then shift that character forward by one.

The jump

half is the largest power of two strictly less than k. Position k lands in the right half, so it is the character at k − half shifted forward by one.

def kthCharacter(self, k: int) -> str: if k == 1: return "a" half = 1 while half * 2 < k: half *= 2 return chr(ord(self.kthCharacter(k - half)) + 1)
