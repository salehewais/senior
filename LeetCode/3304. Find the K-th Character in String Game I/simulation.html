Find the K-th Character

Start from a. While the word is shorter than k, append a copy where every letter moves forward by one. The answer is the character at position k.

The append

Each operation appends the next letter of every character already in the word. In the expression index + 1 % 26, the remainder is computed first. 1 % 26 is 1, so the letter moves forward by one. For k up to 64 the result stays inside a–z.

def kthCharacter(self, k: int) -> str: char = "a" alphabet = "abcdefghijklmnopqrstuvwxyz" while len(char) < k: shifted = "" for i in char: shifted += alphabet[alphabet.index(i) + 1 % 26] char += shifted return char[k - 1]
