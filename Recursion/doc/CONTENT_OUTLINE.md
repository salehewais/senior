# تسلسل التعلم

المرجع مبني عشان السؤال ييجي قبل القالب. كل فصل فيه هدف، شرح، شكل بصري، مثال Python، تتبع، أخطاء، أسئلة، وخلاصة.

## 1. النموذج الذهني

تعريف الـ recursion، ليه بيظهر، والفرق عن الـ iteration. مفهوم إن النسخة الأصغر نفس المسألة، وإن النداء القديم بيتعلق ومش بيتنسى.

## 2. تشريح الـ function

Base case، recursive case، المنطق، النداء، الـ state، التقدم نحو التوقف، والقيمة الراجعة. الشرط المكتوب من غير تقدم مش بيوقف التنفيذ.

## 3. الـ Call Stack

الإطار، النزول، والرجوع. جدول تتبع لـ `countdown(3)` بأعمدة الشغل قبل النداء وبعده، ومتتبع خطوات تفاعلي. حد عمق Python و `RecursionError`.

## 4. أدوار الـ recursive call

قلب المرجع. عنوانان تعليميان، مش تصنيف رسمي:

- Continuation / State-Progression: تحديث الحالة وتسليمها، والناتج يرجع كما هو.
- Recursive-Result Processing: انتظار ناتج ودمجه ثم التكملة.

نفس الدالة ممكن تستخدم الدورين. التقدم، والـ tail position، والقرار بين فرعين مفاهيم منفصلة. factorial مثال على معالجة نتيجة من غير قرار. binary search مثال على قرار ثم continuation.

## 5. Tail و Non-Tail

موضع النداء والشغل المؤجل، على `print_down` و `print_up`. CPython من غير tail-call optimization، فالشكل الـ tail مش بيقلل الـ stack لوحده.

## 6. الإرجاع وإدارة الحالة

تمرير للأمام، إرجاع للخلف، وزوج (ناتج، موضع). الفرق بين factorial ومجموع قائمة وبين countdown اللي أثرها طباعة.

## 7. الأنماط

عائلات متداخلة: linear، tail، non-tail، tree، divide and conquer، traversal، backtracking، parsing متداخل، و memoization. لكل واحدة شكل المسألة، سلوك النداء، مثال، تعقيد، غلطة، ومسألة LeetCode.

## 8. Decode String

استنتاج حالة LeetCode 394 قبل قراءة السطور. تتبع كامل لـ `3[a2[c]]` حتى `accaccacc`، مع دور كل نداء، ومسار الرجوع، وحدود الزمن والمساحة بسبب نسخ النصوص وغياب الـ TCO.

## 9. الصحة والتعقيد

قاعدة فحص: الشرط، التقدم، ما قبل النداء وما بعده، الناتج، العمق، الزمن، المساحة، وشجرة النداءات. أعطال متكررة: loop لا نهائي، index بواحد، حالة متسربة، return ناقص.

## 10. إطار الحل

اتناشر خطوة، متطبقة على عدّ حرف في نص، من تعريف الحالة لحد مقارنة الحل بـ loop.

## 11. تدريب

أربعة عشر تمرينًا: توقع مخرجات، base case، إصلاح التوقف، ترتيب التنفيذ، stack، تمييز الدورين، tail position، ناتج قوس متداخل، عدد نداءات fib، إلغاء اختيار في backtracking، شرط index، وكتابة عكس نص.

## 12. مراجعة

ورقة قصيرة، جدول مقارنة، دليل اختيار، قائمة مراجعة، مسرد إنجليزي بشرح مصري، والالتباسات اللي المرجع متعمد يفصلها.
