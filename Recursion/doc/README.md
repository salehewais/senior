# Recursion Mastery

مرجع دراسة ذاتية عن الـ recursion، بالشرح المصري والمصطلحات الإنجليزية وأمثلة Python.

## فتح الملف

1. افتح `recursion_mastery.html` في أي متصفح حديث.
2. الملف مستقل: CSS و JavaScript جواه، ومن غير إنترنت أو سيرفر أو مفاتيح.

من الطرفية، لو المتصفح الافتراضي متظبط:

```bash
xdg-open recursion_mastery.html
```

## إزاي تستخدمه

- الفهرس على الجانب بينقل بين الفصول. على الشاشة الضيقة افتحه من زر «الفهرس».
- شريط أعلى الصفحة بيبيّن تقدم القراءة.
- زر «الوضع الداكن» بيبدّل الثيم، والاختيار بيتسجل في المتصفح.
- زر «نسخ» فوق كل مثال Python بينسخ الكود.
- التبويبات بتقارن فكرتين من غير ما الصفحة تطول، وتتنقل بينها بلوحة المفاتيح.
- في الفصل 3 والفصل 8 في متتبع خطوات للـ call stack.
- في الفصل 11 اكتب الإجابة واضغط «تحقق». التلميح والحل مقفولين لحد ما تفتحهم.
- ابدأ بالفصل 1، ومتستعجلش للفصل 8. الفصل 4 هو قلب التفرقة بين استمرار الحالة ومعالجة النتيجة.

تسلسل الدراسة مفصل في `CONTENT_OUTLINE.md`.
