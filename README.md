# Road Map — Senior Interview Study Hub

Arabic technical study guides for senior engineer interview prep. Open **`index.html`** in a browser as the entry point (no build step).

## Guides

| File | Topic | Est. study time |
|------|--------|-----------------|
| [rdbms-guide.html](rdbms-guide.html) | SQL, normalization, indexes, ACID | ~40–60 h |
| [problem-solving-guide.html](problem-solving-guide.html) | DSA, 14 patterns, 16-week plan | ~120–160 h |
| [ood-guide.html](ood-guide.html) | OOP pillars, SOLID, 25 patterns | ~50–70 h |
| [system-design-guide.html](system-design-guide.html) | Distributed systems, 25 designs | ~80–120 h |

Shared assets: [roadmap.css](roadmap.css), [roadmap.js](roadmap.js).

## Suggested order

1. **Hub** — read the [30-week master path](index.html#master-roadmap) on `index.html`.
2. **Foundations (weeks 1–4)** — RDBMS + Problem Solving (complexity, arrays/hash).
3. **OOD (weeks 5–8)** — pillars → SOLID → patterns.
4. **DSA depth (weeks 9–16)** — follow the PS `#roadmap`.
5. **System design (weeks 17–28)** — follow the SD `#roadmap`.
6. **Integration (weeks 29–32)** — weekly mocks: coding + system design + LLD.

Each guide has its own weekly `#roadmap` with anchor links into sections.
