1.1 Propositional Logic

Idea in one sentence. A proposition is a declarative sentence that is either true or false — never both, never “maybe.”

Key definitions

Proposition
A statement with a definite truth value (T or F).
\(\neg p\)
Negation: true exactly when \(p\) is false.
\(p \land q\)
Conjunction (AND): true only if both are true.
\(p \lor q\)
Disjunction (OR): true if at least one is true.
\(p \oplus q\)
Exclusive or (XOR): true if exactly one is true.
\(p \to q\)
Conditional: false only when \(p\) is true and \(q\) is false.
\(p \leftrightarrow q\)
Biconditional: true when \(p\) and \(q\) match.

Propositions vs non-propositions

  • Proposition: “7 is prime.” (true)
  • Not a proposition: “Open the door.” (command)
  • Not a proposition: “Is \(n\) even?” (question)
  • Not (yet) a proposition: “\(x + 2 = 5\)” until \(x\) is fixed or quantified.

Interactive truth-table builder

Choose a connective

Conditional language

From \(p \to q\)

  • Converse: \(q \to p\)
  • Inverse: \(\neg p \to \neg q\)
  • Contrapositive: \(\neg q \to \neg p\) (equivalent to original)

Necessary / sufficient

  • “\(p\) is sufficient for \(q\)” ≈ \(p \to q\)
  • “\(p\) is necessary for \(q\)” ≈ \(q \to p\)
  • “\(p\) iff \(q\)” ≈ \(p \leftrightarrow q\)

Compound expression evaluator

Assign truth values, evaluate

Use variables p, q, r and operators ! (not), & (and), | (or), -> (implies), <-> (iff), ^ (xor).

Worked example

Original example

Let \(p\): “The battery is charged.” Let \(q\): “The phone turns on.” Consider \(p \to q\).

If the battery is charged and the phone does not turn on, then \(p\) is T, \(q\) is F, so \(p \to q\) is false. Every other combination makes the implication true — including when the battery is dead (vacuous truth of the implication).

Common mistake Treating \(p \to q\) like “\(p\) causes \(q\)” in everyday English. In logic it is only a truth-table rule: the single F-case is T→F.

1.2 Applications of Propositional Logic

Idea in one sentence. Connectives let you translate specs, puzzles, and search filters into precise T/F structure.

Key definitions

Translation
Map English clauses to atomic propositions, then wire them with connectives.
Consistent specs
A set of requirements that can be true together for some assignment.
Boolean search
AND narrows, OR widens, NOT excludes.

English ↔ logic (original sentences)

Atoms: \(a\): “API is up.” \(c\): “Cache is warm.” \(u\): “Users can log in.”

  • “Users can log in only if the API is up.” → \(u \to a\)
  • “The cache is warm and the API is up.” → \(c \land a\)
  • “Either the API is up or users cannot log in (inclusive).” → \(a \lor \neg u\)

Circuit-style mental model

AND / OR / NOT blocks

p AND q → NOT → OR r = \( (p \land q) \) then \(\neg\), then OR with \(r\)

Think of each gate as a truth-table chip. Wiring order matters; parentheses decide the wiring.

Worked example — short puzzle

Original puzzle

Exactly one of these name tags is truthful:

  1. A: “B’s tag is true.”
  2. B: “A’s tag is false.”

If A were true, B would also be true — but exactly one can be true. So A is false and B is true. Consistent: A lies, B tells the truth.

Common mistake Translating “only if” as \(\leftrightarrow\). “\(u\) only if \(a\)” is \(u \to a\), not \(u \leftrightarrow a\).

1.3 Propositional Equivalences

Idea in one sentence. Two formulas are logically equivalent when they agree on every truth assignment — so you can rewrite without changing meaning.

Key definitions

Tautology
Always true (e.g. \(p \lor \neg p\)).
Contradiction
Always false (e.g. \(p \land \neg p\)).
Contingency
Sometimes true, sometimes false.
\(p \equiv q\)
Logical equivalence: \(p \leftrightarrow q\) is a tautology.

Core laws (reference panel)

Rewrite toolkit

  • De Morgan: \(\neg(p \land q) \equiv \neg p \lor \neg q\); \(\neg(p \lor q) \equiv \neg p \land \neg q\)
  • Implication: \(p \to q \equiv \neg p \lor q\)
  • Double negation: \(\neg\neg p \equiv p\)
  • Distributive: \(p \land (q \lor r) \equiv (p \land q) \lor (p \land r)\)
  • Absorption: \(p \lor (p \land q) \equiv p\)
  • Contrpositive: \(p \to q \equiv \neg q \to \neg p\)

Side-by-side simplification

Start

\(\neg(p \to q)\)

Rewrite

  1. \(\neg(\neg p \lor q)\)
  2. \(\neg\neg p \land \neg q\)
  3. \(p \land \neg q\)

So the negation of an implication is “antecedent true and consequent false.”

Common mistake Negating \(p \to q\) as \(\neg p \to \neg q\). That is the inverse, not the negation. Correct: \(p \land \neg q\).

1.4 Predicates and Quantifiers

Idea in one sentence. Predicates become propositions once you plug in a value or quantify over a domain.

Key definitions

\(P(x)\)
Predicate: a property that depends on \(x\).
Domain
The set of allowed values for the variable.
\(\forall x\, P(x)\)
Universal: true if \(P\) holds for every domain element.
\(\exists x\, P(x)\)
Existential: true if \(P\) holds for at least one element.
Negation
\(\neg\forall x\,P(x)\equiv\exists x\,\neg P(x)\); \(\neg\exists x\,P(x)\equiv\forall x\,\neg P(x)\).

Interactive domain checker

Domain \(\{2,3,4,5\}\), \(P(x)\): “\(x\) is prime”

Click an element to evaluate \(P(x)\).

Pick an \(x\).

Then \(\forall x\,P(x)\) is false (because of 4), while \(\exists x\,P(x)\) is true.

Worked example

Original example

Domain: students in a study group. \(H(x)\): “\(x\) finished the homework.”

\(\neg\forall x\, H(x)\) means “not everyone finished” ≡ \(\exists x\, \neg H(x)\) “someone did not finish.” It does not force “nobody finished.”

Common mistake Reading \(\neg\forall x\,P(x)\) as \(\forall x\,\neg P(x)\). Those differ: “not all” ≠ “none.”

1.5 Nested Quantifiers

Idea in one sentence. When quantifiers nest, order is part of the meaning — swapping \(\forall\) and \(\exists\) can change the claim.

Key definitions

\(\forall x\exists y\)
For each \(x\), you may pick a (possibly different) \(y\).
\(\exists y\forall x\)
One fixed \(y\) must work for every \(x\).
Scope
The portion of the formula a quantifier governs.

Quantifier scope map

Reading \(\forall x\, \exists y\, L(x,y)\)

∀x   // choose any person x
∃y   // there is a locker y for that x
L(x,y)   // x is assigned y

Compare with \(\exists y\, \forall x\, L(x,y)\): one locker shared by everyone.

Translation drill

  • “Every integer has a larger integer.” → \(\forall x \exists y\, (y > x)\) on \(\mathbb{Z}\).
  • “There is an integer larger than every integer.” → \(\exists y \forall x\, (y > x)\) — false on \(\mathbb{Z}\).
  • “Someone is admired by everyone.” → \(\exists y \forall x\, A(x,y)\).
Common mistake Assuming \(\forall x\exists y\, P(x,y)\) implies \(\exists y\forall x\, P(x,y)\). The first allows \(y\) to depend on \(x\); the second does not.

1.6 Rules of Inference

Idea in one sentence. A valid argument is one where the conclusion must be true whenever all premises are true.

Key definitions

Valid
No counterexample assignment makes premises true and conclusion false.
Fallacy
An invalid inference pattern (e.g. affirming the consequent).

Compact rule cards

Modus ponens
p → q p
∴ q
Modus tollens
p → q ¬q
∴ ¬p
Hypothetical syllogism
p → q q → r
∴ p → r
Disjunctive syllogism
p ∨ q ¬p
∴ q
Universal instantiation
∀x P(x)
∴ P(c) for particular c
Universal generalization
P(c) for arbitrary c
∴ ∀x P(x)

Formal-argument stepper

Highlight which rule applies

Premises: (1) \(p \to q\)   (2) \(q \to r\)   (3) \(p\)

Step 1: From (1) and (3) get q  — modus ponens
Step 2: From (2) and q get r  — modus ponens
Conclusion: r
Step 0 of 3
Common mistake Affirming the consequent: from \(p\to q\) and \(q\), conclude \(p\). Invalid — \(q\) might hold for other reasons.

Try it

From \(p\to q\) and \(\neg q\), conclude \(\neg p\). Rule?

1.7 Introduction to Proofs

Idea in one sentence. A proof is a reasoned argument that establishes a mathematical claim from definitions, axioms, and already-proved results.

Key definitions

Theorem
A major statement that has been proved.
Lemma
A helper result used on the way to a theorem.
Corollary
A quick consequence of a theorem.
Conjecture
A proposed claim not yet proved (or disproved).

Three original worked proofs

Direct proof

Claim. If \(n\) is an odd integer, then \(n^2\) is odd.

Proof. Odd means \(n = 2k+1\) for some integer \(k\). Then \[ n^2 = (2k+1)^2 = 4k^2 + 4k + 1 = 2(2k^2+2k) + 1, \] which is odd. □

Proof by contrapositive

Claim. If \(n^2\) is even, then \(n\) is even.

Proof. Contrapositive: if \(n\) is odd, then \(n^2\) is odd — already shown above. □

Proof by contradiction

Claim. \(\sqrt{2}\) is irrational.

Sketch. Assume \(\sqrt{2}=a/b\) in lowest terms. Then \(a^2 = 2b^2\), so \(a\) is even, write \(a=2c\), get \(b\) even — contradicting lowest terms. □

Vacuous and trivial proof intuition

  • Vacuous: \(P\to Q\) is true when \(P\) is never true on the domain (e.g. “if \(n<0\) and \(n\) is a square of an integer…” on nonnegatives).
  • Trivial: \(P\to Q\) when \(Q\) is always true, regardless of \(P\).
Common mistake Starting a “proof” with the conclusion and working backwards without reversing the steps carefully. Prefer forward structure, or clearly mark equivalence steps.

1.8 Proof Methods and Strategy

Idea in one sentence. Different claims invite different tools: cases, construction, uniqueness arguments, or a single counterexample to kill a universal claim.

Key definitions

Exhaustive / cases
Split the domain into pieces that cover all possibilities; prove each piece.
Constructive existence
Exhibit a concrete witness.
Nonconstructive
Show existence without naming the object (e.g. via contradiction or pigeonhole).
Uniqueness
Existence + “suppose two, show they are equal.”
Counterexample
One domain element that falsifies a universal claim.

Strategy checklist

  • Universal claim (“for all…”) → try direct / contrap / contradiction; hunt counterexamples if stuck.
  • Conditional with awkward hypothesis → try contraposive.
  • Existence claim → try to construct; if hard, consider nonconstructive routes.
  • Integer statements with parity/mod → cases (even/odd, mod \(n\)).
  • “Exactly one” → existence + uniqueness.

Worked example — cases

Original example

Claim. For every integer \(n\), \(n(n+1)\) is even.

Proof. Case 1: \(n\) even → product even. Case 2: \(n\) odd → \(n+1\) even → product even. □

Common mistake Offering one example as a “proof” of a universal claim. Examples support intuition; only a general argument (or exhaustive finite check) proves \(\forall\).

Quick review + practice

Idea in one sentence. Symbols and patterns stick when you rewrite, quantify carefully, and pick proof methods on purpose.

Cheat sheet

Symbols

  • \(\neg\) not · \(\land\) and · \(\lor\) or · \(\oplus\) xor
  • \(\to\) implies · \(\leftrightarrow\) iff
  • \(\forall\) for all · \(\exists\) there exists
  • \(\equiv\) logically equivalent

Handy equivalences

  • \(p\to q \equiv \neg p\lor q \equiv \neg q\to\neg p\)
  • \(\neg(p\land q)\equiv\neg p\lor\neg q\)
  • \(\neg\forall x P\equiv\exists x\neg P\)

Inference highlights

  • MP: \(p\to q,\ p\ \Rightarrow\ q\)
  • MT: \(p\to q,\ \neg q\ \Rightarrow\ \neg p\)
  • UI / UG for predicates

Proof menu

  • Direct · Contrapositive · Contradiction
  • Cases · Existence · Uniqueness · Counterexample

Suggested study order / what to practice next

  1. Drill truth tables until \(\to\) and \(\leftrightarrow\) feel automatic.
  2. Translate 10 English sentences each way (especially “only if,” “unless,” “necessary”).
  3. Practice pushing negations through quantifiers.
  4. Write three short proofs: one direct, one contraposive, one by cases.
  5. When stuck on homework, name the method you’re trying before writing algebra.
