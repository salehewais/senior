الخطوة 1Step 1

البوابةGateway

كل طلب يمر من هنا قبل أي خدمة. Traefik ثابت من ملف، بلا مقبس Docker، فلا يكتشف الحاويات. المسارات في ملف ثانٍ. فحص الرمز يثبت التوقيع ولا يقرأ الدور. إضافة edgeheaders تحذف ترويسات الهوية وتضبط CORS ومعرّف الارتباط. Every request passes here before any service. Traefik is a static file, with no Docker socket, so it does not discover containers. Routes live in a second file. The token check verifies the signature and does not read a role. The edgeheaders plugin drops identity headers and sets CORS plus the correlation id.

gateway/traefik.yaml

الوظيفة التقنيةTechnical role

إعداد ثابت للبوابة التعليمية. مزوّد الملفات فقط، والملف يُراقب. مقبس Docker غير مركّب، فـ Traefik لا يكتشف الحاويات الأخرى. لوحة التحكم مغلقة. insecure معطّل، فترويسة X-Forwarded-For من العميل ليست عنوانه. سجل الوصول JSON: يُسقط Authorization ويبقي X-Correlation-Id. Static configuration for the learning gateway. File provider only, and the file is watched. The Docker socket is not mounted, so Traefik does not discover other containers. The dashboard is off. insecure is false, so a client-supplied X-Forwarded-For is not the client IP. The access log is JSON: Authorization is dropped and X-Correlation-Id is kept.

قيمة التعلمWhat to learn

البوابة لا ترى إلا ما كُتب في الملف. إغلاق الاكتشاف يمنع مساراً يظهر لأن حاوية بدأت، لا لأن أحداً قصده. The gateway sees only what the file names. Turning discovery off keeps a route from appearing because a container started, rather than because someone meant it.

gateway/dynamic.yaml

الوظيفة التقنيةTechnical role

مسارات عامة نحو عمليات على الجهاز عبر host.docker.internal: خدمة الطلب على 8000، والتقارير على 8001، والواجهة على 5173. تلك العمليات ليست جزءاً من مشروع Compose هذا. التقارير مسار بأولوية أعلى، ومسار الطلب يستبعد البادئة نفسها. حد المعدل في ذاكرة Traefik: عداد لكل عملية، وغالباً عداد لعنوان الجسر، وليس ميزانية الدخول أو إنشاء الطلب داخل خدمة الطلب. edge-prepare يحذف ترويسات الهوية قبل ForwardAuth نحو jwt-check. Public routers toward host processes through host.docker.internal: the order service on 8000, reporting on 8001, and the frontend on 5173. Those processes are not part of this Compose project. Reports are a higher-priority router, and the order router excludes that prefix. The rate limit is Traefik’s in-memory limiter: one counter per process, often one counter for the bridge address, and it is not the login or order-create budget inside the order service. edge-prepare strips identity headers before ForwardAuth to jwt-check.

قيمة التعلمWhat to learn

هذا الملف يعلّم البوابة وهي تتحدث مع عمليات المضيف. المكدس الكامل يستبدله بملف يوجّه داخل الشبكة. This file teaches the gateway while it talks to host processes. The full stack replaces it with a file that routes inside the network.

gateway/jwt_check.py

الوظيفة التقنيةTechnical role

فحص RS256 يستدعيه Traefik عبر ForwardAuth. العملية معها المفتاح العام لخدمة الطلب فقط، ولا تصدر رموزاً. لا تقرأ دوراً ولا سعراً ولا رقم مخزون ولا طلباً. الرمز يجب أن يحمل exp وiat وsub وأن يكون token_type=access. ما يمر هنا تتحقق منه خدمة الطلب أو التقارير مرة أخرى. An RS256 check used by Traefik ForwardAuth. The process has the order-service public key only and does not issue tokens. It does not read a role, a price, a stock figure, or an order. The token must carry exp, iat, and sub, and token_type must be access. A request that passes here is verified again by the order service or the reporting service.

قيمة التعلمWhat to learn

الحافة تثبت أن التوقيع صحيح. سياسة «من يحق له هذا الفعل» تبقى داخل الخدمة، لأن البوابة لا تعرف الدور. The edge proves the signature is valid. Who may take an action stays inside the service, because the gateway does not know the role.

edgeheaders.go

الوظيفة التقنيةTechnical role

وسيط Traefik محلي. وضع prepare يحذف ترويسات هوية العميل، يطبّع X-Correlation-Id، ويختم ذلك المعرّف مع ترويسات CORS الخاصة بواجهة المتجر على الاستجابة. وضع cors يجيب OPTIONS هنا حتى لا يصل preflight إلى فحص JWT ولا إلى الخدمة. قائمة الأصول ليست *. الحزمة لا تقرأ طلبات ولا أسعاراً ولا مخزوناً ولا أدواراً. A local Traefik middleware. prepare drops client identity headers, normalizes X-Correlation-Id, and stamps that id plus the storefront CORS headers onto the response. cors answers OPTIONS here so a browser preflight never reaches the JWT check or an upstream. The allow-list is not *. The package does not read orders, prices, stock, or roles.

قيمة التعلمWhat to learn

العميل لا يختار هويته بترويسة. طلب المتصفح التمهيدي يتوقف عند الحافة ولا يُحسب فحصاً للرمز. A client does not choose an identity with a header. The browser preflight stops at the edge and is not counted as a token check.

الخطوة 2Step 2

الحاوياتCompose

المكدس المحلي الكامل على شبكة واحدة اسمها commerce. المنفذ العام الوحيد هو البوابة. سكربت التشغيل ينشئ مفاتيح JWT وملف .env ثم يشغّل المكدس. ملف التوجيه هنا يصل إلى أسماء داخل الشبكة، لا إلى عمليات المضيف. The full local stack sits on one network named commerce. The only public port is the gateway. The start script creates JWT keys and a .env file, then starts the stack. The route file here reaches names inside the network, not host processes.

compose/docker-compose.yml

الوظيفة التقنيةTechnical role

شبكة واحدة، commerce، والحاويات تجد بعضها باسم DNS في Compose. مسار HTTP العام هو منفذ البوابة فقط. إدارة RabbitMQ وواجهة Odoo منافذ تعلم خاصة على 127.0.0.1. Postgres و Redis غير منشورين، فـ Postgres على المضيف عند 5432 لا يصطدم بهذا الملف. الصور المبنية موسومة 0.1.0 (و Odoo 18.0.1)، ووسم latest غير مستخدم. لا تشغّل deploy/gateway/compose.yaml في الوقت نفسه: كلاهما ينشر 127.0.0.1:8080. HTTP على localhost، وهذا ليس نشراً إنتاجياً. One network, commerce. Containers find each other by Compose DNS name. Only the gateway HTTP port is the public path. RabbitMQ management and the Odoo UI are private learning ports on 127.0.0.1. Postgres and Redis are not published, so a host Postgres on 5432 does not collide with this file. Built images are tagged 0.1.0 (Odoo 18.0.1). The tag latest is not used. Do not run deploy/gateway/compose.yaml at the same time: both publish 127.0.0.1:8080. HTTP on localhost. This is not a production deploy.

قيمة التعلمWhat to learn

المكدس الكامل يغلق قواعد البيانات والذاكرة عن الجهاز، ويبقي باباً واحداً. ملفات الخدمة الواحدة تبقى لتجربة جزء، وهذا الملف يجمعها. The full stack keeps databases and the cache off the host and leaves one door. The single-service files stay for trying one piece; this file gathers them.

compose/up.sh

الوظيفة التقنيةTechnical role

يشغّل مكدس Compose الكامل من جذر المستودع. ينشئ مفاتيح JWT وdeploy/compose/.env حين يغيبان. لا يحذف المجلدات. يخرج بغير صفر إذا كان Docker متوقفاً أو فشل Compose. المفاتيح الموجودة لا تُستبدل. Starts the full Compose stack from the repository root. Creates JWT keys and deploy/compose/.env when they are missing. Does not delete volumes. Exits non-zero when Docker is down or Compose fails. Keys that already exist are not replaced.

قيمة التعلمWhat to learn

التشغيل المتكرر آمن: ينقصه السر فينشئه، ويجده فيتركه، ولا يمسح بيانات من تشغيل سابق. A second run is safe: a missing secret is created, an existing one is left alone, and data from an earlier run is not wiped.

compose/dynamic.yaml

الوظيفة التقنيةTechnical role

مسارات المكدس الكامل. الوجهات أسماء DNS في Compose على شبكة commerce. deploy/gateway/dynamic.yaml هو الملف الآخر، ويصل إلى عمليات على المضيف. نداءات التنفيذ غير مذكورة: Odoo ينادي خدمة الطلب على http://order-service:8000 داخل هذه الشبكة. Public routers for the full stack. Upstreams are Compose DNS names on the commerce network. deploy/gateway/dynamic.yaml is the other file: it reaches processes on the host. Fulfillment callbacks are not listed. Odoo calls the order service at http://order-service:8000 on this network.

قيمة التعلمWhat to learn

داخل المكدس، العنوان اسم خدمة. ما يحدث بين Odoo وخدمة الطلب لا يُنشر على البوابة. Inside the stack, the address is a service name. What happens between Odoo and the order service is not published on the gateway.

الخطوة 3Step 3

المخططاتObservability

Prometheus يسحب /metrics مباشرة. المجمّع يمرّر التتبع فقط إلى Tempo. Grafana تعرض اللوحات. Alertmanager يرسل إلى خطاف يطبع سطراً JSON، بلا بريد. Prometheus scrapes /metrics directly. The collector forwards traces only, to Tempo. Grafana shows the boards. Alertmanager sends to a hook that prints one JSON line, with no mail.

observability/prometheus/prometheus.yml

الوظيفة التقنيةTechnical role

قائمة سحب المرحلة 12. الفاصل 15 ثانية، والاحتفاظ قصير. هذه العملية ليست مطلوبة لإتمام الشراء. كل مهمة تطلب /metrics من الخدمة نفسها، ثم تُرسل القواعد إلى Alertmanager. The phase 12 scrape list. The interval is 15 seconds and retention is short. This process is not required for checkout. Each job asks /metrics of the service itself, then the rules go to Alertmanager.

قيمة التعلمWhat to learn

المقاييس لا تمر بالمجمّع. عطل التتبع لا يخفي معدل الخطأ، والشراء لا ينتظر Prometheus. Metrics do not pass through the collector. A tracing outage cannot hide an error rate, and checkout does not wait on Prometheus.

observability/otel/collector.yaml

الوظيفة التقنيةTechnical role

تتبع فقط. مقاييس التطبيق يسحبها Prometheus مباشرة حتى لا يخفي عطل المجمّع معدل الخطأ. المستقبل OTLP، والمعالج دفعة، والمصدّر يرسل إلى tempo:4317. Traces only. Application /metrics are scraped by Prometheus directly so a collector outage cannot hide an error rate. The receiver is OTLP, the processor is a batch, and the exporter sends to tempo:4317.

قيمة التعلمWhat to learn

خطان منفصلان: رقم يُسحب، وأثر يُدفع. سقوط أحدهما لا يُسقط الآخر. Two separate lines: a number that is pulled, and a trace that is pushed. One falling does not drop the other.

observability/grafana/provisioning/datasources/datasources.yml

الوظيفة التقنيةTechnical role

Grafana تقرأ Prometheus مصدراً افتراضياً على http://prometheus:9090، وTempo على http://tempo:3200. اللوحات الجاهزة في observability/grafana/dashboards/: نظرة المنصة، التبعيات، مسار الطلب، الدفع، تأخر التقارير، والـ outbox مع الوسيط. Grafana reads Prometheus as the default source at http://prometheus:9090, and Tempo at http://tempo:3200. The prepared boards live in observability/grafana/dashboards/: platform overview, dependencies, the order path, payment, reporting lag, and the outbox with the broker.

قيمة التعلمWhat to learn

اللوحة لا تجمع. هي نافذة على ما سحبه Prometheus وما خزّنه Tempo. A board does not collect. It is a window onto what Prometheus scraped and what Tempo stored.

observability/webhook/hook.py

الوظيفة التقنيةTechnical role

مصبّ خطاف Alertmanager. يكتب سطراً JSON واحداً لكل تنبيه إلى stdout: الحالة، والاسم، والشدة، والملخص، والوصف. بلا بريد، وبلا سر، وبلا نداء خارج هذه العملية. السجل هو docker logs. في alertmanager.yml مستقبل واحد يجمع حسب اسم التنبيه حتى لا يصبح هدف واحد خمسين إشعاراً. Alertmanager webhook sink. It writes one JSON line per alert to stdout: status, name, severity, summary, and description. No email, no secret, and no call out of this process. docker logs is the record. In alertmanager.yml one receiver groups by alert name so one down target does not become fifty notifications.

قيمة التعلمWhat to learn

التنبيه يُشاهَد أولاً في السجل. القناة الخارجية تأتي لاحقاً، بعد أن يفهم المسار. An alert is seen first in the log. An outside channel comes later, after the path is understood.

الخطوة 4Step 4

النسخة الاحتياطيةBackup

نسخة واحدة من Postgres بصيغة custom: order_db أو reporting_db أو odoo_db. الاستعادة تطلب --yes. Redis و RabbitMQ لا يُنسخان. One Postgres copy in custom format: order_db, reporting_db, or odoo_db. Restore requires --yes. Redis and RabbitMQ are not copied.

backup/dump.sh

الوظيفة التقنيةTechnical role

ينسخ قاعدة Postgres واحدة في Compose بصيغة custom عبر pg_dump. Redis ذاكرة تخزين مؤقت ولا يُنسخ. RabbitMQ لا يُنسخ. القاعدتان الأخريان لا تدخلان الأمر نفسه. الاسم المقبول هو order_db أو reporting_db أو odoo_db، وكل واحدة على خدمة Postgres الخاصة بها. اسم الملف ليس اسم القاعدة، والاسم يُقرأ من ترويسة الأرشيف. Dumps one Compose Postgres database in custom format with pg_dump. Redis is a cache and is not dumped. RabbitMQ is not dumped. The other two databases are not dumped. The accepted name is order_db, reporting_db, or odoo_db, each on its own Postgres service. The file name is not the database name; the name is read from the archive header.

قيمة التعلمWhat to learn

النسخ قرار عن قاعدة واحدة. الكاش والوسيط ليسا مصدر الحقيقة، فلا يُعاملان كنسخة. A dump is a choice of one database. The cache and the broker are not the source of truth, so they are not treated as a copy.

backup/restore.sh

الوظيفة التقنيةTechnical role

يستبدل الكائنات داخل قاعدة Postgres واحدة من ملف custom. يتطلب --yes ويطبع اسم القاعدة التي سيُستبدل محتواها. لا يسقط القاعدتين الأخريين، ولا يسقط بيانات RabbitMQ أو Redis. Redis لا يُستعاد. الاستعادة ليست إرجاعاً للوسيط. Replaces objects inside one Compose Postgres database from a custom-format dump. It requires --yes and prints the database name it is about to replace. It does not drop the other two databases, and it does not drop RabbitMQ or Redis data. Redis is not restored. A restore is not a rewind of the broker.

قيمة التعلمWhat to learn

--yes يمنع استبدالاً صامتاً. إعادة القاعدة لا تعيد الطوابير إلى لحظة النسخ. --yes blocks a silent replace. Putting a database back does not put the queues back to the moment of the dump.

الخطوة 5Step 5

الضغطLoad

مسار لطيف: مستخدمان، انتظار 15 ثانية، تحت حدود Redis. مسار إغراق يتجاوز حد إنشاء الطلب. Locust ينفّذ المسار عبر البوابة على 127.0.0.1:8080. A gentle path: two users, a 15-second wait, under the Redis limits. A flood path crosses the order-create limit. Locust runs the path through the gateway at 127.0.0.1:8080.

load/scenario.py

الوظيفة التقنيةTechnical role

خطة تصفح العميل وإنشاء الطلب لاختبار الحمل. هذه الوحدة لا تفتح مقبساً، وملف Locust يستدعيها. الحدود هي ما تفرضه خدمة الطلب و Traefik أصلاً، والملف لا يغيّرها. اللطيف: مستخدمان وانتظار 15 ثانية. الإغراق: مستخدم واحد وانتظار 0.2 ثانية ومحاولات إنشاء تتجاوز 10 في الدقيقة بخمس. الدخول والتسجيل 5 في الدقيقة، وإنشاء الطلب 10 في الدقيقة، ومحدد Traefik في الذاكرة 30 طلباً في الثانية. العنوان الافتراضي http://127.0.0.1:8080. The customer browse and order-create plan for the load test. This module does not open a socket; the Locust file calls it. The limits are the ones the order service and Traefik already enforce, and this file does not change them. Gentle: two users and a 15-second wait. Flood: one user, a 0.2-second wait, and create attempts that pass 10 per minute by five. Login and register are 5 per minute, order create is 10 per minute, and Traefik’s in-memory limiter is 30 requests per second. The default address is http://127.0.0.1:8080.

قيمة التعلمWhat to learn

الاختبار يصف الميزانية ولا يرفعها. اللطيف يبقى تحت حد Redis، والإغراق يعبر حد إنشاء الطلب عمداً. The test describes the budget and does not raise it. Gentle stays under the Redis limit, and flood crosses the order-create limit on purpose.

load/locustfile.py

الوظيفة التقنيةTechnical role

مسار عميل واحد: تسجيل أو إعادة استخدام، ثم دخول، وتصفح المنتجات، وإنشاء طلب واحد، وقراءته. الوضع اللطيف يبقى تحت حد Redis لإنشاء الطلب. وضع الإغراق يعبره. لا أحد منهما ينادي مساراً داخلياً. التشغيل عبر البوابة. One customer path: register or reuse, log in, browse products, create one order, and read it. Gentle mode stays under the Redis order-create limit. Flood mode crosses it. Neither mode calls an internal route. The run goes through the gateway.

قيمة التعلمWhat to learn

Locust ينفّذ الخطة من خارج البوابة كما يفعل المتصفح. الضغط لا يقفز إلى منفذ خدمة داخلي. Locust runs the plan from outside the gateway, the way a browser does. The load does not jump to an internal service port.

الخطوة 6Step 6

مختبر العطلFailure lab

lib.sh يسمح فقط بـ stop أو start لخدمة واحدة. إيقاف RabbitMQ يُبقي صف الـ outbox معلقاً. إيقاف Redis يجعل تسجيل الدخول وإنشاء الطلب يفشلان بشكل مغلق، بينما قراءة الكتالوج تبقى من Postgres. lib.sh allows only stop or start for one service. Stopping RabbitMQ leaves the outbox row pending. Stopping Redis makes login and order create fail closed, while a catalog read still comes from Postgres.

failure-lab/lib.sh

الوظيفة التقنيةTechnical role

مساعدات مشتركة لمختبر العطل. سكربتات التجربة تستورد هذا الملف، وهو ليس تجربة بذاته. فشل docker info يعود قبل أي إيقاف أو تشغيل في Compose. الدالة تقبل stop أو start فقط، ولخدمة واحدة هي SERVICE التي سمّاها السكربت. أي أمر آخر أو خدمة أخرى يُرفض. Shared helpers for the failure lab. Experiment scripts source this file. It is not a drill by itself. A failing docker info returns before any Compose stop or start. The helper accepts only stop or start, and only the one service named SERVICE by that script. Any other command or service is refused.

قيمة التعلمWhat to learn

المختبر لا يملك أمراً يُسقط المكدس. العطل المقصود خدمة واحدة، حتى يبقى الباقي شاهداً على ما تغيّر. The lab has no command that drops the stack. The intended fault is one service, so the rest stays up as a witness to what changed.

failure-lab/rabbitmq.sh

الوظيفة التقنيةTechnical role

يوقف RabbitMQ فقط. نداء HTTP للطلب ما زال يُثبَّت في order_db. صف الـ outbox يبقى pending. خدمة الطلب وناشر الـ outbox يبقيان يعملان، لأن الواجهة لا تنادي الوسيط مباشرة. تشغيل الوسيط من جديد يفرّغ الناشر الصف. بعد خمس محاولات فاشلة يصبح الصف failed، وهذا ليس طابور رسائل ميتة لدى المستهلك. Stops RabbitMQ only. The order HTTP call still commits in order_db. The outbox row stays pending. The order service and the outbox publisher stay up, because the API does not call the broker. Starting the broker again lets the publisher drain the row. After five failed attempts the row becomes failed, and that is not a consumer dead-letter queue.

قيمة التعلمWhat to learn

نجاح الطلب لا يعني أن الحدث غادر القاعدة. الصف يعلّق حتى يعود الوسيط، والصف التجاري نفسه لا يتغير. A successful order does not mean the event left the database. The row waits until the broker returns, and the business row itself does not change.

failure-lab/redis.sh

الوظيفة التقنيةTechnical role

يوقف Redis فقط. قراءة الكتالوج ما زالت تستخدم order_db: ذاكرة المنتجات تعامل Redis الميت كإخفاق وتقرأ من Postgres. تسجيل الدخول وإنشاء الطلب يفشلان مغلقاً بـ 503 وDEPENDENCY_UNAVAILABLE قبل كتابة صف طلب، ومدقق كلمة المرور لا يعمل. jwt-check لا يستخدم Redis. التأكيد وقراءة الطلب والتحديث والخروج لا تستخدم Redis. الطلبات لم تُخزَّن فيه أصلاً. Stops Redis only. Catalog reads still use order_db: the product cache treats a dead Redis as a miss and reads Postgres. Login and order create fail closed with 503 and DEPENDENCY_UNAVAILABLE, before an order row is written, and the password checker does not run. jwt-check does not use Redis. Confirm, order read, refresh, and logout do not use Redis. Orders were never stored in Redis.

قيمة التعلمWhat to learn

الفشل المغلق يرفض الكتابة حين يغيب حد المعدل. القراءة ترجع إلى القاعدة، والرمز الذي صدر قبل العطل يبقى صالحاً للمسارات التي لا تحتاج Redis. Fail closed refuses a write when the rate-limit store is gone. A read falls back to the database, and a token issued before the fault still works on routes that do not need Redis.

kind/apply.sh

الوظيفة التقنيةTechnical role

يبني وسوم صور Compose، يحمّلها في kind، ويطبّق deploy/kind. لا يحذف عنقوداً. Compose يبقى بيئة التشغيل الأولى. إن وُجد العنقود commerce يُترك كما هو. إن غاب Docker أو kind أو kubectl لا يُنشأ عنقود. Builds the Compose image tags, loads them into kind, and applies deploy/kind. Does not delete a cluster. Compose remains the first runtime. If the commerce cluster already exists, it is left as it is. If Docker, kind, or kubectl is missing, a cluster is not created.

قيمة التعلمWhat to learn

Kubernetes هنا هدف ثانٍ بعد أن يعمل المكدس محلياً. إعادة السكربت لا تمسح عنقوداً قائماً لتعيد البناء من صفر. Kubernetes here is a second target after the stack already runs locally. Running the script again does not wipe a living cluster to start from zero.

kind/kustomization.yaml

الوظيفة التقنيةTechnical role

أحمال مساحة الاسم commerce: التخزين، والقواعد، والوسيط، والذاكرة، والخدمات، والواجهة، والبوابة، والمراقبة، والدخول. ملف Secret المثال ليس مورداً. apply.sh ينشئ ConfigMaps من ملفات deploy/observability وdeploy/gateway وdeploy/compose/dynamic.yaml قبل تطبيق هذا الملف. Workloads for the commerce namespace: storage, databases, the broker, the cache, the services, the frontend, the gateway, observability, and ingress. The example Secret file is not a resource. apply.sh creates the ConfigMaps that mount files from deploy/observability, deploy/gateway, and deploy/compose/dynamic.yaml before this is applied.

قيمة التعلمWhat to learn

العنقود يعيد استخدام توجيه Compose وملفات المراقبة. الأسرار المثال ليست جزءاً من التطبيق. The cluster reuses the Compose routes and the observability files. The example secrets are not part of the apply.
